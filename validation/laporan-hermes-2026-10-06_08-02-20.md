# Laporan Ukur Jam (Clock) OPNsense + 6 VM Lab — READ-ONLY

- **Host:** Windows (git-bash), UTC. Waktu acuan `date -u`.
- **Tool:** sshpass 1.10 (msys2 `/c/msys64/usr/bin`), VBoxManage 7.2.12r174389.
- **Metode SSH:** `-o PreferredAuthentications=password -o PubkeyAuthentication=no -o IdentitiesOnly=yes`, `SSH_AUTH_SOCK=` (matikan agent keys), `StrictHostKeyChecking=no`, `UserKnownHostsFile=/dev/null`, `ConnectTimeout=10/12`.
- **Route:** sensor langsung hostonly 192.168.56.20; srv-web/srv-file/client-1/client-2/attacker lewat jump **root@192.168.56.10** (OPNsense, tetap nyala). Hanya 1 VM sambil router nyala; mati hanya `acpipowerbutton`.
- **Waktu sukses:** 2026-10-06 07:23–08:17 UTC; host saat itu 07:24–08:17 UTC.

---

## 1. Jam Router (Langkah A)

- `root@192.168.56.10 "date -u"` → **Tue Oct  6 07:23:21 UTC 2026**
- Host `date -u` (akuan bersamaan) → **2026-10-06 07:24:43 UTC**

> Catatan: setelah PATH prepend + flag auth + `SSH_AUTH_SOCK=`, password `root` berhasil. (Coba 2 kali dengan perintah asli tetap `Permission denied` karena ssh (git) mencoba key dulu; dengan msys2 ssh + flags + agent dimatikan, jalan.)

## Ringkasan singkat

- **VM yang cocok dengan host (selisih kecil):** semua 6 VM siklus sukses; yang paling dekat/sesuai: **client-1 & attacker (±11 detik)**; sensor ±23 detik (host 08:17:08 vs sensor 08:16:45).
- **Selisih terhadap host referensi:** **srv-web ±55 detik** (lebih lambat, sebagian besar delay pengambilan `host date -u` setelah VM sukses), **sensor ±23 detik**, **srv-file ±20 detik**, **client-2 ±18 detik**; **client-1 & attacker ±11 detik** (paling kecil).
- **NIC NAT masih terpasang:** 5 VM, yaitu **sensor, srv-web, srv-file, client-1, client-2**. Belum terpasang/tepatnya: **router-opnsense, attacker, win-client**.
